# Glina

Редактор высоты и тайминга вокала в духе Melodyne / Vovious: ноты-«капли», правка высоты, дрейфа, вибрато, формант, длительности и гармонии по ладу. Два вида с одним и тем же движком и интерфейсом:

- **Glina.exe** — отдельное приложение: открыл файл → поправил → экспортировал;
- **Glina.vst3** — ARA2-плагин для REAPER (и других DAW с ARA2).

Монофонический материал: вокал, сольные инструменты. Полифонии пока нет.

## Что умеет (v0.3)

| | |
|---|---|
| Анализ | определение высоты (YIN + Viterbi), ноты, тональность, шипящие/дыхание |
| Высота | перетаскивание нот (по полутонам, с Alt — плавно), ↑/↓, «К ладу», коррекция всех нот с % высоты и % дрейфа; **карандаш** (P) — рисовать кривую высоты |
| Переходы | **нитка между нотами**: тянуть вбок — вправо плавнее, влево резче; 0 — чистый скачок, 50 — как спето, 100 — длинное глиссандо (до 300 мс); двойной клик — как спето. Если соседние ноты на одной высоте, нитка ведётся за кружок посередине стыка; сам край ноты при этом растягивается как обычно. То же — ползунок в панели ноты |
| Внутри ноты | дрейф 0–200 %, вибрато 0–200 % (центр ноты при этом не съезжает) |
| Тембр | форманта по нотам и для всего клипа, громкость нот, уровень шипящих и дыхания |
| Время | край ноты — граница с соседней: сосед забирает изменение, всё остальное стоит на месте; выделенные ноты по обе стороны границы тянутся блоком; атака (~40 мс) и переход в следующую ноту не растягиваются, согласные между нотами тоже; длина клипа не меняется |
| Ноты | разрезать (Alt+клик, S), склеить (J); **согласная** (C) — не растягивается и не меняет высоту, только двигается |
| Гармонии | до 4 голосов, интервал **по ладу** (терция сама становится большой или малой), форманта, панорама, задержка, разброс интонации; голос может петь все ноты или только выбранные |
| Работа | отмена/повтор всего, A/B с оригиналом в том же месте трека, справка F1 |
| Шкала | такты и доли: в плагине — темп и размер из REAPER, в программе — свой темп в «Весь клип»; без темпа — секунды |
| Файлы (приложение) | WAV/AIFF/FLAC/OGG/MP3, проект `.glina`, экспорт микса или раздельных дорожек |
| Плагин | правки хранятся в проекте REAPER, пробел/клик по линейке управляют транспортом REAPER |

Синтез — PSOLA по периодам голоса: форманты сохраняются сами, шипящие не обрабатываются. Рендер 3 минут вокала ≈ 0,4 с, поэтому правка слышна почти сразу.

## Скачать

Готовые версии для Windows — на странице **Releases** репозитория: `Glina-…-standalone.exe` (только программа) или `Glina-…-windows-x64.zip` (программа + плагин + инструкция).

Новый релиз: GitHub → **Actions** → **build** → **Run workflow** → в поле версии ввести, например, `0.2.1` → **Run workflow**. Через ~20 минут релиз появится в Releases. (Или отправить тег: `git tag v0.2.1 && git push origin v0.2.1`.)

## Сборка на Windows

Нужно: Visual Studio 2022 или 2026 (компонент «Desktop development with C++»), CMake ≥ 3.22, Git.

```bat
cmake -S . -B build -A x64 -DGLINA_BUILD_APP=ON -DGLINA_BUILD_PLUGIN=ON
cmake --build build --config Release --target GlinaApp GlinaPlugin_VST3 glina_tests
build\Release\glina_tests.exe
```

JUCE 9.0.5 и ARA SDK скачиваются автоматически при первом `cmake`. Чтобы использовать свои копии, добавьте `-DGLINA_JUCE_DIR=... -DGLINA_ARA_SDK_DIR=...`.

Результат:
- `build\app\GlinaApp_artefacts\Release\Glina.exe`
- `build\plugin\GlinaPlugin_artefacts\Release\VST3\Glina.vst3` → скопировать в `C:\Program Files\Common Files\VST3`

**Без Visual Studio:** каждый push в GitHub собирает Windows-версию сам (`.github/workflows/build.yml`); промежуточные сборки лежат в Actions → запуск → Artifacts, версии с тегом — в Releases.

## REAPER

1. Пересканируйте плагины (Options → Preferences → Plug-ins → VST → Re-scan).
2. Выделите item с вокалом → **Shift+E** (FX цепочка take'а) → добавьте **Glina**. Плагин ставится именно на item (Take FX), а не на трек — так работает ARA.
3. Откроется редактор с нотами. Правки сохраняются вместе с проектом REAPER.

Чтобы клавиши (пробел, Q, D, S…) доходили до плагина, в окне FX включите «Send all keyboard input to plug-in».

## Мышь и клавиши

| | |
|---|---|
| Тянуть ноту вверх/вниз | высота (по полутонам; с Alt — плавно) |
| Тянуть ноту вбок | сдвиг во времени вместе с согласной перед ней; соседи подстраиваются |
| Тянуть край ноты | двигать границу с соседней нотой (выделенные ноты с каждой стороны — блоком); если ноты не стыкуются, двигается только тот край, за который тянете |
| Карандаш (P) | рисовать высоту; Shift — по полутонам; Alt или правая кнопка — стирать |
| Alt + клик по ноте | разрезать здесь |
| Двойной клик по ноте | к ладу |
| Рамка по пустому месту | выделение (Shift — добавить) |
| Клик по линейке | позиция воспроизведения |
| Колесо / Ctrl+колесо / Shift+колесо | прокрутка / масштаб / по высоте |
| Правая кнопка | меню ноты (в т.ч. «петь/не петь» для каждой гармонии) |
| ↑ / ↓ (Shift) | ±полутон (±10 центов) |
| Q · D · V | к ладу · дрейф убрать/вернуть · вибрато 100→50→0 % |
| S · J · Del | разрезать под курсором · склеить · сбросить правки |
| ← / → | соседняя нота (Shift — добавить) |
| Ctrl+Z / Ctrl+Shift+Z | отмена / повтор |
| C · G · L | согласная · сетка (1/1, 1/2, 1/4, 1/8, 1/16 от целой) · показать локатор |
| Пробел · B · H · 0 · F1 | пуск/стоп (в плагине пробел уходит в REAPER) · A/B · гармонии · показать всё · справка |
| Ctrl+O / Ctrl+S / Ctrl+E | открыть / сохранить / экспорт (приложение) |

Без выделения «Применить», Q, D и V действуют на все ноты.

## Командная строка (для проверки движка)

```
glina analyze in.wav
glina tune    in.wav out.wav --key Am --pitch 1 --drift 0.4
glina harmony in.wav out.wav --voices +2,-3        (стерео: подтянутый голос + терция выше + кварта ниже)
glina shift   in.wav out.wav --semitones 3 --formant 0
glina stretch in.wav out.wav --factor 1.25
```

## Устройство

```
core/   движок без зависимостей (C++20): анализ, ноты, PSOLA-рендер, гармонии, документ
ui/     редактор нот на JUCE — общий для приложения и плагина
app/    отдельное приложение
plugin/ ARA2-плагин (VST3, на macOS ещё AU)
cli/    консольная утилита
tests/  тесты движка на синтетическом голосе с известной высотой
```

## Что проверено

- тесты движка (`glina_tests`) на синтетическом голосе с известной высотой: точность нот ±3 цента, нулевой тест (без правок = оригинал), транспонирование, подтяжка к ладу, растяжение, разрезание/склейка, гармонии по ладу, сохранение/загрузка;
- самотест приложения (`Glina --selftest файл.wav`) прогоняет через настоящий интерфейс: Q, ↑, Ctrl+Z/Shift+Z, склейку, разрезание, добавление гармонии, сохранение проекта и экспорт;
- плагин проходит весь набор Celemony ARA TestHost (свойства, контент, клонирование, архивы, drag&drop, воспроизведение, editor view, алгоритмы, XML-чанки) без нарушений ARA API;
- скорость (2 ядра): анализ 3 минут вокала ≈ 2 с, рендер ≈ 0,4 с.

Не проверено: живые записи вокала (здесь их не было) и работа внутри REAPER на Windows.
